## About the Project

**Happy Som** is a small informational website dedicated to the Königsberg Catfish Monument in Kaliningrad. It brings together the monument's story, local legends, photographs, interesting facts, and directions to the location.

The website content is currently in Russian. This repository is also a hands-on project for practising frontend fundamentals without a large framework.

## Features

- **Monument overview** — an introductory section with a short description and a main photograph.
- **History and local legend** — background information about the monument and the stories associated with it.
- **Photo carousel** — previous/next controls, navigation dots, automatic slide rotation, and pause-on-hover behaviour.
- **Interactive accordion** — expandable legend content.
- **Interesting facts** — compact cards with information about the monument and its location.
- **Location shortcut** — opens the monument's location in Yandex Maps.
- **Small playful interaction** — the “Feed the catfish” button displays a random message and animated bubbles.
- **Mobile navigation** — a burger menu and smooth anchor scrolling.

## Run Locally

No build tools or package manager are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/F1Nfx/happy-som.git
   cd happy-som
   ```

2. Open `index.html` in your browser.

The page loads jQuery, fonts, and several photographs from external services, so an internet connection is required for all external resources to appear.

## Notes

This is a learning and portfolio project, not an official website of the monument or the city. Some images and external resources are hosted by third-party services.
